THE IDEA

A current, not a hit

Attack was a single hard strike: static plates, corner ticks, a tactical grid, warm red over cool cyan. Surge inverts the temperature and the tense. It is energy building rather than landing, so the language becomes directional — waveform instead of grid, a rising bar instead of four ticks, a sweep instead of a halo.

Structure and scoring do not move. This is a palette, type and motif substitution on the same app, and someone glancing at a screenshot should be able to name the volume without reading a word.

Motif

Directional and kinetic, where August was architectural
Waveform, not grid
The 46px tactical grid behind every screen becomes a single low-opacity surge trace. Same job, same cost — one repeating SVG instead of two linear-gradients. Drifting is optional; the shape alone carries it.

Where the skin earns itself
This screen is 48 rows deep. It is where August's language broke down — every row carried corner ticks, a photo, a pill strip and a big red total, so the accent marked nothing and the podium meant nothing.
01Only the top three carry a rising bar, and only first place carries the bloom. Ranks 4+ are a plain table. One card signature, spent where it means something.
02The pinned YOU row is the one place amber appears on this screen. It is the only row that is about the person holding the phone, so it gets the warm accent and nothing else does.
03The active segment of the series toggle is a solid cyan fill — the same treatment as the primary button on HOME, so "the filled cyan thing is the live one" holds across the app.
04Biggest climber is a fact inside Mazin's row rather than a striped banner above the list. In August it was the heaviest object on the screen and it was decoration.
05Thin rows run about 42pt against August's 88. The ranked field now fits in roughly three screens instead of ten, and the 0–3 point tail collapses behind a disclosure.
Structure here is Part A of the handoff, already built in index-v2.html. Only the colour, type and bar are new.

HOW THIS LANDS IN CODE
The August skin is already a stack of override layers at the bottom of the file, each one a commented block that re-points a handful of custom properties and a few background-image rules. Surge is the same shape: one more layer that redefines --red, --tick, --glow and --ease-out, swaps the four tick gradients for one bar, replaces the grid on body::before, and adds the display-font axis. Component JSX does not need to change — the only literal hex values sitting inline are in the screens I rewrote last turn, and those are a short find-and-replace.
